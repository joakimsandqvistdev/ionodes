# Contributing

Use Node.js 20 or newer. Install dependencies with `npm install`, start the demo with `npm run dev`, and run `npm test`, `npm run lint`, `npm run typecheck`, `npm run format:check`, and `npm run build` before submitting changes. Keep the graph schema domain-neutral and add tests for behavior changes. Record lasting architecture decisions in `docs/decisions/`.
